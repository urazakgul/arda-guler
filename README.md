# Arda Güler

A single-screen, no-scroll page that charts Arda Güler's goal contributions and minutes,
match by match, for Real Madrid, the Türkiye national team and Fenerbahçe.

- **Team dropdown** in the title switches between Real Madrid, Türkiye and Fenerbahçe (`#real-madrid`, `#turkiye`, `#fenerbahce` also work as links).
- **Cumulative lines** for goal contributions, goals, assists (left axis) and minutes (right axis).
- **Matches in order**: the x-axis is match sequence, so off-season and injury gaps are skipped.
- **Hover, tap or arrow keys** to inspect any match: score, minutes, goals, assists and running totals.
- **Download image** exports a clean PNG of the page (no tooltip).
- Light and dark theme follow the system setting. Works on phones.

Plain HTML, CSS and JavaScript. No build step, no dependencies, no network requests.
